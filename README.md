IndieVerse
Sobre o Projeto
IndieVerse é um sistema com o principal intuíto de ser um marketplace simplificado para desenvolvedores independentes listarem seus jogos sem nenhuma dor de cabeça.
---
Perfis
Desenvolvedor: Responsável por publicar a sua obra-prima, seu jogo, na plataforma.
Jogador: Usuário que vai adquirir os jogos listados na plataforma.
---
Regras de Negócio
O Jogador adquire uma Licença de uso do Jogo, ele não é dono do jogo, mas tem a permissão de usufruir do produto.
Jogador só consegue ver na sua biblioteca os jogos que ele adquiriu!
Desenvolvedor conseguirá visualizar os seus jogos lançados.
Os jogos terão uma nota baseada nas reviews dos jogadores.
---
Requisitos Funcionais
    1. Cadastro de jogos com categoria, preço e requisitos mínimos.
    2. Carrinho de compras e simulação de checkout.
    3. Biblioteca pessoal do jogador (ManyToMany entre Jogador e Jogo).
    4. Sistema de avaliações (review) pós-compra.
